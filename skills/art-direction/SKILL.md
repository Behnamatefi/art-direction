# Art direction

Read `art-direction.md` at the root of this repository before designing or reviewing an artifact. It is the source of truth for tokens, typography, layout, accessibility, language, theme, motion, and medium-specific guidance. If the skill was installed separately and the root file is unavailable, fetch it from `https://raw.githubusercontent.com/Behnamatefi/art-direction/main/art-direction.md`.

1. Identify the requested medium and read its section in §10, including §10.4 for mobile and §10.5 for long proposals or reports when relevant.
2. Ask whether the user wants English only or multiple languages unless already specified. If no answer is available, proceed in English. For multilingual work, confirm the languages and apply their native typography and direction.
3. Include a theme changer by default in interactive work. Support dark and light in every selected language. Provide theme variants for static exports.
4. Inspect the flow for purposeful motion using the frequency, purpose, timing, and function gates in §9. Suggest a small number of specific opportunities and explain representative rejections. Implement motion when the user requests implementation. An opportunity-only review stays read-only.
5. Review the finished artifact and its motion against §9 and §12. Check the actual output, interruption, reduced motion, relevant states, and sizes where possible. Report unresolved failures and checks that could not be performed.

The user's explicit instructions take precedence when they conflict with the guide. Keep project-specific data and business terms supplied by the user separate from the reusable visual direction.
